NotesMd is a native Android application designed for seamless local note-taking with full Markdown rendering support. Built entirely in Kotlin, the project adheres strictly to Clean Architecture and MVVM principles, ensuring a robust separation of concerns by keeping the business logic completely platform-independent. The user interface leverages Jetpack Compose for a modern, reactive layout, while data persistence is handled offline via Room database with optimized indexing for fast textual search, all seamlessly glued together using Hilt for dependency injection.
